# XMusic client

The XMusic web app: React 19, TypeScript, Vite, Redux Toolkit and Tailwind CSS.

Setup, scripts and the full feature list are in the [main README](../README.md).

```bash
npm run dev     # start on http://localhost:5173
npm run build   # type-check and build into dist/
npm run lint
```

The API address comes from `VITE_API_URL` (default `http://localhost:3000`);
set it in `client/.env.local` if your API runs elsewhere.
